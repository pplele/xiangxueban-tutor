## 一、实数与代数式

### 1. 实数

**相反数**：像 1 和 $-1$、3 和 $-3$ 这样，只有符号不同的两个数互为相反数。特别地，0 的相反数是 0。

**绝对值**：一般地，数 $a$ 的绝对值记作 $|a|$，当 $a \geqslant 0$ 时，$|a| = a$；当 $a < 0$ 时，$|a| = -a$。

【点拨】两个负数比大小，绝对值大的反而小。

**倒数**：若 $ab = 1$，则 $a$ 与 $b$ 互为倒数。若 $ab = -1$，则 $a$ 与 $b$ 互为负倒数。

### 2. 因式分解

**因式分解**：把一个多项式化成几个整式的积的形式。常用的因式分解的方法有：

（1）提公因式法

找公因式（各项相同的部分），提取出来，将多项式写成公因式与另一因式的乘积。

例如：$-8a^2b + 12ab^2 - 4ab = -4ab(2a - 3b + 1)$。

（2）公式法

**平方差公式**：$a^2 - b^2 = (a + b)(a - b)$。〔记忆口诀〕平方差 = 两项和 × 两项差。

例如：$m^2 - 4n^2 = m^2 - (2n)^2 = (m + 2n)(m - 2n)$。

**完全平方公式**：$a^2 \pm 2ab + b^2 = (a \pm b)^2$。

例如：$25x^2 + 20xy + 4y^2 = (5x)^2 + 2 \cdot 5x \cdot 2y + (2y)^2 = (5x + 2y)^2$。

**立方和、差公式**：$a^3 + b^3 = (a + b)(a^2 - ab + b^2)$，$a^3 - b^3 = (a - b)(a^2 + ab + b^2)$。

例如：$x^3 - 8y^3 = x^3 - (2y)^3 = (x - 2y)(x^2 + 2xy + 4y^2)$。

（3）十字相乘法

对于多项式 $x^2 + px + q$，若存在数 $a$、$b$，使 $a \cdot b = q$，且 $a + b = p$，则 $x^2 + px + q = (x + a)(x + b)$。

【例 1】分解因式：$x^2 + 3x + 2$。

【精析】$x^2 + 3x + 2 = x^2 + (1 + 2)x + 1 \times 2 = (x + 1)(x + 2)$。

【图】十字相乘示意图：左侧竖排写二次项系数的分解 $1$、$1$，右侧竖排写常数项的分解 $1$、$2$，交叉相乘再相加（$1 \times 2 + 1 \times 1 = 3$）等于一次项系数；右边相乘等于常数项，交叉相乘再相加等于一次项系数。

【出处：库课数学教材 书p2 / PDF p10】

### 3. 分式

分式 $\dfrac{A}{B}$ 有意义的条件是分母不能为 0，即 $B \neq 0$。

【例 2】求使 $\dfrac{x}{2x-4}$ 有意义的 $x$ 的取值范围。

【精析】若使 $\dfrac{x}{2x-4}$ 有意义，须满足 $2x - 4 \neq 0$，解得 $x \neq 2$。

（1）分式的运算性质

**性质 1** 分式的分子与分母乘（或除以）同一个不等于 0 的整式，分式的值不变，即 $\dfrac{A}{B} = \dfrac{A \cdot C}{B \cdot C}$（或 $\dfrac{A}{B} = \dfrac{A \div C}{B \div C}$）。

主要应用于：① 把分子、分母中各项的系数化为整数，不改变分式的值；② 分子、分母与分式本身的符号，改变其中任何两个，分式的值不变；③ 约分、化简分式。例如：

$$\frac{x}{\frac{x}{2}+1} = \frac{x}{\left(\frac{x}{2}+1\right) \cdot 2} = \frac{2x}{x+2}; \qquad \frac{x^2}{2y} = \frac{-x^2}{-2y} = -\frac{x^2}{2y}; \qquad \frac{ma+mb-mc}{a+b-c} = \frac{m(a+b-c)}{a+b-c} = m.$$

**性质 2**

① $\dfrac{a}{b} \pm \dfrac{c}{b} = \dfrac{a \pm c}{b}$；

② $\dfrac{a}{b} \pm \dfrac{c}{a} = \dfrac{ad}{bd} \pm \dfrac{bc}{bd} = \dfrac{ad \pm bc}{bd}$；

③ $\dfrac{a}{b} \cdot \dfrac{c}{d} = \dfrac{a \cdot c}{b \cdot d}$；

④ $\dfrac{a}{b} \div \dfrac{c}{d} = \dfrac{a}{b} \cdot \dfrac{d}{c} = \dfrac{a \cdot d}{b \cdot c}$。

【例 3】化简 $\dfrac{2x}{x^2-1} - \dfrac{1}{x-1}$。

【精析】原式 $= \dfrac{2x}{(x+1)(x-1)} - \dfrac{x+1}{(x+1)(x-1)} = \dfrac{2x - (x+1)}{(x+1)(x-1)} = \dfrac{x-1}{(x+1)(x-1)} = \dfrac{1}{x+1}$。

（2）正分数（式）比较大小

| 类型 | 比较大小的方法 | 举例 |
|---|---|---|
| 同分母 | 分子越大，分数（式）越大 | $\dfrac{3}{7} < \dfrac{5}{7}$ |
| 同分子 | 分母越大，分数（式）越小 | $\dfrac{2}{5} > \dfrac{2}{9}$ |
| 分子、分母都不同 | 找分母的最小公倍数，通分后按同分母比较 | $\dfrac{2}{3}$ 与 $\dfrac{3}{5}$ 比较：$\dfrac{2}{3} = \dfrac{2 \times 5}{3 \times 5} = \dfrac{10}{15}$，$\dfrac{3}{5} = \dfrac{3 \times 3}{5 \times 3} = \dfrac{9}{15}$，故 $\dfrac{2}{3} > \dfrac{3}{5}$ |

### 4. 二次根式

（1）二次根式的概念及有意义的条件

形如 $\sqrt{a}\ (a \geqslant 0)$ 的式子叫作二次根式。

（2）二次根式的性质

① $\sqrt{a} \geqslant 0$；

② $(\sqrt{a})^2 = a$；

③ $\sqrt{a^2} = |a| = \begin{cases} a, & a > 0, \\ 0, & a = 0, \\ -a, & a < 0. \end{cases}$

（3）有理化

通过适当的变形去掉代数式分母中根号的运算叫作分母有理化，通过适当的变形去掉代数式分子中根号的运算叫作分子有理化。我们常常利用平方差公式化去代数式分母或者分子中的根号。

【例 4】对 $\dfrac{1}{\sqrt{x^2+1}-x}$ 进行分母有理化。

【精析】$\dfrac{1}{\sqrt{x^2+1}-x} = \dfrac{\sqrt{x^2+1}+x}{(\sqrt{x^2+1}-x)(\sqrt{x^2+1}+x)} = \dfrac{\sqrt{x^2+1}+x}{(\sqrt{x^2+1})^2 - x^2}$

$$= \frac{\sqrt{x^2+1}+x}{x^2+1-x^2} = \sqrt{x^2+1} + x.$$

【例 5】对 $\dfrac{\sqrt{x+1}-1}{x}$ 进行分子有理化。

【精析】$\dfrac{\sqrt{x+1}-1}{x} = \dfrac{(\sqrt{x+1}-1)(\sqrt{x+1}+1)}{x(\sqrt{x+1}+1)} = \dfrac{(\sqrt{x+1})^2 - 1}{x(\sqrt{x+1}+1)}$

$$= \frac{x+1-1}{x(\sqrt{x+1}+1)} = \frac{1}{\sqrt{x+1}+1}.$$

【图】例 5 精析中分子有理化过程注记：分子乘共轭因式 $(\sqrt{x+1}-1)(\sqrt{x+1}+1)$ 后分子化为 $(x+1)-1$。

### 2. 一元一次方程的解法

一元一次方程 $kx + b = 0$ 移项化简可得其解是 $x = -\dfrac{b}{k}$。该解是一元一次函数 $y = kx + b$ 中 $y = 0$ 时 $x$ 的值，也是函数图象与 $x$ 轴交点 $\left(-\dfrac{b}{k}, 0\right)$ 的横坐标。

【出处：库课数学教材 书p4 / PDF p12】

【例 6】解方程 $2 - 2x = 2x - 6$。

【精析】移项得 $-2x - 2x = -6 - 2$，合并同类项得 $-4x = -8$，解得 $x = 2$。

### 3. 不等式

一般地，用符号 $>$、$<$、$\geqslant$、$\leqslant$、$\neq$ 表示大小关系的式子，叫作不等式。

对于两个任意的代数式 $a$ 和 $b$，有 $a - b > 0 \Leftrightarrow a > b$；$a - b \neq 0 \Leftrightarrow a \neq b$；$a - b < 0 \Leftrightarrow a < b$。

| 性质 | 内容 |
|---|---|
| 传递性 | $a > b, b > c \Rightarrow a > c$ |
| 可加性 | $a > b \Rightarrow a + c > b + c$ |
| 可乘性 | $a > b,\ c > 0 \Rightarrow ac > bc$；$a > b,\ c < 0 \Rightarrow ac < bc$ |
| 可乘方性 | $a > b > 0 \Rightarrow a^n > b^n\ (n \in \mathbf{N}, n \geqslant 2)$ |
| 可开方性 | $a > b > 0 \Rightarrow \sqrt[n]{a} > \sqrt[n]{b}\ (n \in \mathbf{N}, n \geqslant 2)$ |

$a > b$，且 $a$、$b$ 同号，则 $\dfrac{1}{a} < \dfrac{1}{b}$；$a > 0 > b$，即 $a$、$b$ 异号，则 $\dfrac{1}{a} > 0 > \dfrac{1}{b}$。

【例 7】已知 $0 \leqslant a \leqslant 1$，则 $a^2$ ______ $a^3$。（填 $>$、$=$ 或 $<$）

【精析】若 $0 \leqslant a \leqslant 1$，则 $a^2 \geqslant 0$，$a \cdot a^2 \leqslant 1 \cdot a^2$，即 $a^3 \leqslant a^2$，且等号仅在 $a = 0$ 与 $a = 1$ 处成立。

〔答案〕$\geqslant$

### 4. 一元一次不等式的解法

① 当 $a > 0$ 时，$ax \geqslant b$ 的解集为 $x \geqslant \dfrac{b}{a}$；

② 当 $a < 0$ 时，$ax \geqslant b$ 的解集为 $x \leqslant \dfrac{b}{a}$；

③ $\lvert ax + b \rvert \leqslant c \Leftrightarrow -c \leqslant ax + b \leqslant c$；

④ $\lvert ax + b \rvert \geqslant c \Leftrightarrow ax + b \geqslant c$ 或 $ax + b \leqslant -c$。

【例 8】不等式 $4 + 3x \geqslant x + 2$ 的解集是（　　）

A. $x \geqslant 1$　　B. $x \geqslant -1$　　C. $x \leqslant 1$　　D. $x \leqslant -1$

【精析】$4 + 3x \geqslant x + 2$ 移项整理得 $2x \geqslant -2$，即 $x \geqslant -1$。故选 B。

〔答案〕B

【例 9】不等式 $\lvert x - 1 \rvert < 1$ 的解集为（　　）

A. $-2 < x < 0$　　B. $x > 0$　　C. $x < 2$　　D. $0 < x < 2$

【精析】由 $\lvert x - 1 \rvert < 1$ 可得 $-1 < x - 1 < 1$，则 $-1 + 1 < x - 1 + 1 < 1 + 1$，故 $0 < x < 2$。

〔答案〕D

### 7. 二次函数与一元二次方程 $ax^2 + bx + c = 0\,(a \neq 0)$、不等式的解集之间的关系

$a > 0$ 时讨论如下：

| 项目 | $\Delta = b^2 - 4ac > 0$ | $\Delta = b^2 - 4ac = 0$ | $\Delta = b^2 - 4ac < 0$ |
|---|---|---|---|
| 方程 $ax^2+bx+c=0$ 的根 | 求根公式 $x_{1,2} = \dfrac{-b \pm \sqrt{b^2-4ac}}{2a}$，两个不相等的实根 $x_1, x_2$ | 两个相等的实根 $x_1 = x_2$ | 无实根 |
| $y = ax^2+bx+c$ 与 $x$ 轴的交点 | 有两个交点 （抛物线与 $x$ 轴交于 $A(x_1,0)$、$B(x_2,0)$ 两点） | 有一个交点 （抛物线与 $x$ 轴相切于点 $A(x_1,0)$） | 无交点 （抛物线与 $x$ 轴不相交） |
| 不等式 $ax^2+bx+c>0$ 的解集 | $x < x_1$ 或 $x > x_2$ | $x \neq x_1$（或 $x \neq x_2$） | 全体实数 |
| 不等式 $ax^2+bx+c<0$ 的解集 | $x_1 < x < x_2$ | 无解 | 无解 |

当判别式 $\Delta = b^2 - 4ac < 0$ 时，一元二次方程没有实根，但是在复数域内存在复数根 $x_{1,2} = \dfrac{-b \pm \mathrm{i}\sqrt{4ac - b^2}}{2a}$。

$a < 0$ 时类比即可。

【例 11】求方程 $x^2 + 6x + 13 = 0$ 的根。

【精析】$x^2 + 6x + 13 = x^2 + 6x + 9 + 4 \xlongequal{\text{配方法}} (x + 3)^2 + 4 = 0$，故方程无实根。

【点拨】$\mathrm{i}$ 是复数单位，$\mathrm{i}^2 = -1$。

### 8. 二元一次方程组的解法

求解二元一次方程组的主要方法为消元法。下面举例说明。

【例 12】解方程组 $\begin{cases} 5x + 3y = 4, \\ x - y = 0. \end{cases}$

【精析】**方法一**　代入消元法

由 $x - y = 0$ 可得 $x = y$，将 $x = y$ 代入 $5x + 3y = 4$ 中可得 $8x = 4$，解得 $x = \dfrac{1}{2}$，故 $y = \dfrac{1}{2}$，即方程组的解为 $\begin{cases} x = \dfrac{1}{2}, \\ y = \dfrac{1}{2}. \end{cases}$

**方法二**　加减消元法

令 $\begin{cases} 5x + 3y = 4, \quad ① \\ x - y = 0. \quad ② \end{cases}$　① $+ 3 \times$ ② 得 $8x = 4$，解得 $x = \dfrac{1}{2}$，将其代入 ② 可得 $y = \dfrac{1}{2}$，即方程组的解为 $\begin{cases} x = \dfrac{1}{2}, \\ y = \dfrac{1}{2}. \end{cases}$

【例 13】解方程组 $\begin{cases} y = x^2, \\ x - y + 2 = 0. \end{cases}$

【精析】由 $x - y + 2 = 0$ 可得 $y = x + 2$，将 $y = x + 2$ 代入 $y = x^2$ 中可得 $x + 2 = x^2$，即 $x^2 - x - 2 = (x - 2)(x + 1) = 0$，解得 $x_1 = -1, x_2 = 2$，故 $y_1 = 1, y_2 = 4$，即方程组的解为 $\begin{cases} x = -1, \\ y = 1 \end{cases}$ 和 $\begin{cases} x = 2, \\ y = 4. \end{cases}$

## 三、集合与不等式组

### 1. 集合

常用数集包括自然数集 $\mathbf{N}$、正整数集 $\mathbf{N}^*$ 或 $\mathbf{N}_+$、整数集 $\mathbf{Z}$、有理数集 $\mathbf{Q}$ 和实数集 $\mathbf{R}$。

集合 $A$ 与 $B$ 的**交集**表示为 $A \cap B$，如 $\{x \mid 0 < x < 3\} \cap \{x \mid 1 < x < 2\} = \{x \mid 1 < x < 2\}$；**并集**表示为 $A \cup B$，如 $\{x \mid 0 < x < 1\} \cup \{x \mid 1 \leqslant x < 2\} = \{x \mid 0 < x < 2\}$。

### 2. 不等式组

| 不等式组（设 $a < b$） | $\begin{cases} x \leqslant a, \\ x \leqslant b \end{cases}$ | $\begin{cases} x \geqslant a, \\ x \geqslant b \end{cases}$ | $\begin{cases} x \geqslant a, \\ x \leqslant b \end{cases}$ | $\begin{cases} x \leqslant a, \\ x \geqslant b \end{cases}$ |
|---|---|---|---|---|
| 数轴表示 | 阴影在 $a$ 处向左  | 阴影在 $b$ 处向右  | 阴影在 $a$、$b$ 之间  | 无公共阴影  |
| 解集 | $x \leqslant a$ | $x \geqslant b$ | $a \leqslant x \leqslant b$ | 空集 |
| 口诀 | 同小取小 | 同大取大 | 大小、小大中间找 | 大大、小小无处找 |

【图】数轴表示示意：四条数轴均标出 $a$、$b$ 两点（$a$ 在左 $b$ 在右），第 1 条在 $a$ 点向左画阴影线，第 2 条在 $b$ 点向右画阴影线，第 3 条在 $a$ 与 $b$ 之间画阴影线，第 4 条 $a$ 向左与 $b$ 向右两部分无重叠。

解不等式组的步骤为：

① 分别求出不等式组中各不等式的解集；

② 将各不等式的解集在数轴上表示出来；

③ 在数轴上找出各不等式解集的公共部分，这个公共部分即不等式组的解集。

【例 14】解不等式组 $\begin{cases} 4x - 5 > 2x + 3, \\ x^2 - 5x - 6 < 0. \end{cases}$

【精析】$4x - 5 > 2x + 3$，移项整理得 $2x > 8$，两边同除以 2 解得 $x > 4$。

$x^2 - 5x - 6 = (x + 1)(x - 6) < 0$，得 $-1 < x < 6$。

两个不等式的解集在数轴上如右图所示，故不等式组的解集为 $4 < x < 6$。

| 角 $\beta$ | $2k\pi + a\ (k \in \mathbf{Z})$ | $\pi + a$ | $-a$ | $\pi - a$ | $\dfrac{\pi}{2} - a$ | $\dfrac{\pi}{2} + a$ |
|---|---|---|---|---|---|---|
| $\sin\beta$ | $\sin a$ | $-\sin a$ | $-\sin a$ | $\sin a$ | $\cos a$ | $\cos a$ |
| $\cos\beta$ | $\cos a$ | $-\cos a$ | $\cos a$ | $-\cos a$ | $\sin a$ | $-\sin a$ |

【例 15】$\cos \dfrac{7\pi}{3} = $ ________。

【精析】$\cos \dfrac{7\pi}{3} = \cos\left(\dfrac{\pi}{3} + 2\pi\right) = \cos \dfrac{\pi}{3} = \dfrac{1}{2}$。

〔答案〕$\dfrac{1}{2}$
