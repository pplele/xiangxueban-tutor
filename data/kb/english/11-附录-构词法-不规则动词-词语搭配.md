## 附录一 构词法

英语中常见的构词法有派生法、合成法和转化法。

| 分类 | 常见情况 | 示例 |
| --- | --- | --- |
| 派生法 | 在一个单词的前面加上一个前缀构成新词 | 表否定：im-/in-/un-/dis-(不)：impolite 不礼貌的；incomplete 不完整的；unfair 不公平的；disagree 不同意 |
| 派生法 | 在一个单词的前面加上一个前缀构成新词 | 表位置、方向：fore-(前)/out-(外,出)/trans-(跨,转)：forearm 前臂；outside 外部；transnational 跨国的 |
| 派生法 | 在一个单词的前面加上一个前缀构成新词 | 表时间、顺序：ex-(前)/re-(再)：ex-husband 前夫；reuse 再次使用 |
| 派生法 | 在一个单词的前面加上一个前缀构成新词 | 表程度：over-(过于)/under-(不足)：overwork 过度工作；underestimate 低估 |
| 派生法 | 在一个单词的后面加上一个后缀构成新词 | 构成名词：-or/-er/-ess/-ion/-ment/-ness：director 导演；foreigner 外国人；hostess 女主人；action 行为；development 发展；darkness 黑暗 |
| 派生法 | 在一个单词的后面加上一个后缀构成新词 | 构成动词：-ize/-en：realize 实现；deepen 加深 |
| 派生法 | 在一个单词的后面加上一个后缀构成新词 | 构成形容词：-ish/-able/-ful/-ous/-less：foolish 愚蠢的；comfortable 舒适的；careful 谨慎的；humorous 幽默的；selfless 无私的 |
| 派生法 | 在一个单词的后面加上一个后缀构成新词 | 构成副词：-ly/-ward(s)：slowly 缓慢地；backward(s) 向后 |
| 合成法 | 把两个或两个以上的单词结合在一起构成新词 | 复合名词：bookstore 书店；greenhouse 温室 |
| 合成法 | 把两个或两个以上的单词结合在一起构成新词 | 复合代词：everyone 每人；himself 他自己 |
| 合成法 | 把两个或两个以上的单词结合在一起构成新词 | 复合动词：overcome 克服；understand 理解 |
| 合成法 | 把两个或两个以上的单词结合在一起构成新词 | 复合形容词：hard-working 工作努力的；handmade 手工制作的 |
| 合成法 | 把两个或两个以上的单词结合在一起构成新词 | 复合副词：somehow 不知怎么地；sometime 在某时 |
| 转化法 | 词形不变，把一个单词从一种词性转化为另一种词性 | 名词转动词：dream n. 梦→vt. 做梦 |
| 转化法 | 词形不变，把一个单词从一种词性转化为另一种词性 | 动词转名词：drink v. 喝→n. 饮料 |
| 转化法 | 词形不变，把一个单词从一种词性转化为另一种词性 | 形容词转动词：dry adj. 干燥的→vt. (使)变干 |
| 转化法 | 词形不变，把一个单词从一种词性转化为另一种词性 | 形容词转名词：sweet adj. 甜的→n. 糖果 |
| 转化法 | 词形不变，把一个单词从一种词性转化为另一种词性 | 形容词转副词：fast adj. 快的→adv. 快 |
