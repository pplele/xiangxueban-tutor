# 拍题问老师 · 微信小程序端

教材拍照 → 识别题干 → 查历史错题 → 多轮对话讲懂 → 要点存回错题本 的移动端闭环。
后端复用 `apps/server`（Fastify + PostgreSQL + RAG），不另起服务。

## 一、目录结构

```
apps/miniprogram/
├─ app.js / app.json / app.wxss     小程序入口与全局样式
├─ project.config.json              IDE 工程配置（appid 需替换）
├─ utils/config.js                  后端地址、演示账号、功能开关
├─ utils/api.js                     请求封装（登录、识题、查重、问答、入库）
└─ pages/
   ├─ index/                        拍照 + 语音说明 + 识别结果确认
   ├─ chat/                         错题复发提醒 + 对话式答疑 + 要点存错题本
   └─ wrongbook/                    错题列表 + 备注编辑
```

## 二、跑起来需要三步

### 1. 确认 appid（已填好）

`project.config.json` 里已写入 `wxe1bc1da8cc0eaea3`，正常情况下不用再动。
换小程序时：登录 https://mp.weixin.qq.com → 开发管理 → 开发设置 → AppID(小程序ID)。

### 2. 确认后端地址

`utils/config.js` 里 `BASE_URL` 默认是 `http://192.168.1.100:8849`，即本机 WLAN 地址。
- 换 Wi-Fi 或换电脑后要同步修改
- 手机与电脑必须在同一网段
- 后端要监听 `0.0.0.0`（当前已是），Windows 防火墙需放行 8849

`project.config.json` 已设 `"urlCheck": false`，即开发者工具「不校验合法域名」，
这样 http + 局域网 IP 才能通。正式上线必须换成 https 域名并在小程序后台配置。

### 3. 打开工程

微信开发者工具 → 导入项目 → 选择本目录 → 填入 AppID → 编译。
真机预览需手机与电脑同网段，点工具栏「预览」扫码。

## 三、拍照与答疑链路的接口

| 接口 | 作用 | 耗时实测 |
|---|---|---|
| `POST /api/capture/ocr` | 图片 → 题干文本（`glm-4v-plus`） | 6.4s |
| `POST /api/capture/wrong-match` | 指纹精确 + 向量相似查重 | 0.6s |
| `POST /api/chat/ask-sync` | RAG 检索 + 讲解 + 引用（非流式，可连续追问） | 8s |
| `POST /api/chat/summarize` | 把整段对话压成 3~5 条备注要点 | 1.2s |
| `POST /api/capture/wrong-save` | 题目 / 解析 / 备注 入库 | 1.5s |

## 四、对话式答疑

讲解页不是「一次性给答案」，而是一问一答的对话，直到学生听懂：

- 首轮：题目 + 学生的疑问一起发，老师给出完整讲解
- 追问：页面底部输入框随时继续问；三个快捷标签覆盖「还是没懂，讲简单点」
  「这一步为什么」「再举个例子」三种最常见情况
- 上下文：每轮请求都带同一 `sessionId`，后端把最近 20 条消息作为 history 注入 Prompt；
  检索时会用首轮的原始题目做锚点，避免「为什么这一步」这种短句检索跑偏
- 收尾：点「存错题」先生成对话要点（3~5 条）填进备注，解析取首轮完整讲解，
  学生确认/改写后入库；同题重复保存会自动合并

识别结果**必须让用户确认后再发送**：视觉模型对数学公式有误读风险，
且查重依赖识别文本算指纹，错字会导致查不到历史错题。`uncertain` 字段会把
模型自己标记的可疑片段回显到页面上提示核对。

## 五、语音输入（默认关闭）

当前 `utils/config.js` 里 `USE_VOICE_PLUGIN: false`，页面只显示文字输入框。

启用步骤：

1. 登录 https://mp.weixin.qq.com → 设置 → 第三方设置 → 插件管理 → 添加「微信同声传译」
2. 在 `app.json` 顶层加：

```json
"plugins": {
  "WechatSI": { "version": "0.3.5", "provider": "wx069ba97219f66d99" }
}
```

3. 把 `utils/config.js` 的 `USE_VOICE_PLUGIN` 改成 `true`
4. 重新编译

开着插件但没在后台添加时，IDE 会直接编译失败，所以默认关掉。

## 六、本地自检（不依赖开发者工具）

开发者工具的 CLI 在某些内测版本上会把小程序误判为小游戏（报 `game.json: 未找到`），
所以补了两个脚本，改完代码先在终端里跑一遍：

```bash
# 静态体检：页面四件套、wxml 事件绑定是否有对应函数、{{变量}} 是否都在 data 里、跳转目标是否注册
node scripts/check-miniprogram.mjs

# 联调冒烟：登录 → 建会话 → 提问 → 追问 → 要点总结 → 查重 → 入库 → 列表 → 改备注
node scripts/smoke-miniprogram.mjs
```

冒烟脚本调真实后端，会真跑两轮大模型（约 18s）；跑完自动删除自己写入的测试题与会话，
加 `--keep` 可保留现场排查。

## 七、常见问题

### 编译报错 `game.json: 未找到 game.json 文件`

不是工程的问题，是开发者工具把项目类型认成了小游戏。按顺序试：

1. 关掉报错窗口，在工具首页「最近项目」里删掉这个工程，重新「导入项目」并选本目录
2. 仍不行：升级开发者工具到最新稳定版（帮助 → 检查更新）
3. 确认 `project.config.json` 第一行是 `{`（不能带 BOM 或其他字符）

`compileType` 必须是 `miniprogram`，`appid` 不能为空或 `wx0000000000000000` 这类占位值。

### 真机预览白屏 / 连不上服务器

1. 手机与电脑连同一个 Wi-Fi（当前电脑 WLAN 是 `192.168.1.100`）
2. Windows 防火墙放行 8849 端口
3. 手机浏览器打开 `http://192.168.1.100:8849/api/health`，能返回 JSON 说明网络通
4. 换网络后要同步改 `utils/config.js` 的 `BASE_URL`

## 八、已知限制

1. 登录用固定演示账号（`utils/config.js`），正式版应改成 `wx.login` + 后端换 openid。
2. 错题原图只存了本地临时路径（`image_url` 字段），小程序重启后失效；
   要长期保留需接对象存储。
3. 查重相似阈值 0.75，语义相近但题面差异大的题可能漏判；精确层依赖文本指纹，
   题干改动一个字就会漏。
4. 多轮上下文取最近 20 条消息、单条截断 1500 字；同一会话问太久会丢最早的细节，
   想换题请重新拍，不要在同一会话里换题。
5. 题干在页面间用 `globalData.pendingAsk` 传递（不走 URL），
   因此从聊天页返回再进拍照页会清空，属预期行为。
